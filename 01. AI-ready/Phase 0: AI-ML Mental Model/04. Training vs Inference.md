# Training vs Inference

## 1. Training

Training is the process in which a model **learns patterns from data by adjusting its parameters** to minimize a loss function.

### How it works
1. Feed training data into the model.
2. Perform a forward pass to generate predictions.
3. Calculate the loss by comparing predictions with targets.
4. Use backpropagation to calculate gradients.
5. Use an optimizer, such as Adam, to update model parameters.
6. Repeat until the model learns useful patterns.

**Example:** Training a language model to predict the next token in a sequence.

## 2. Inference

Inference is the process of **using a trained model to generate predictions or outputs** for new inputs.

### How it works
1. Provide an input to the trained model.
2. Perform a forward pass using its learned parameters.
3. Generate a prediction or output.
4. Return the result.

During ordinary inference, model parameters are not updated.

**Example:** Asking ChatGPT a question and receiving an answer.

## 3. Key Differences

| Feature | Training | Inference |
|---|---|---|
| Purpose | Learn patterns | Use learned patterns |
| Data | Training data | New input data |
| Parameters | Updated | Normally unchanged |
| Backpropagation | Used in standard gradient-based training | Not needed for ordinary inference |
| Compute | Often very intensive | Depends on model and input |
| Example | Training an LLM on text | Generating a response with an LLM |

## 4. Training vs Inference in LLMs

**Training:**
- The model learns to predict the next token.
- The prediction error produces a loss.
- Gradients update the model's weights.

**Inference:**
- The model receives a prompt.
- It predicts the next token using its learned weights.
- The generated token is added to the context, and the process repeats until generation stops.

## Remember

- **Training = Learning**
- **Inference = Using what was learned**

A model's knowledge is encoded in its learned parameters, while inference uses those parameters to produce outputs.
