# Self-Supervised Learning

## 1. What is Self-Supervised Learning?

Self-supervised learning is a machine learning approach where a model **generates supervision from the data itself**, rather than relying on manually labeled data.

The model learns by predicting hidden or missing parts of the input.

**Example:** Predicting the next word in a sentence.

Input: `The sun rises in the ___`

Target: `east`

The original text provides the training signal automatically, without requiring a human to label each example.

## 2. How Does It Work?

1. Collect unlabeled data, such as text or images.
2. Create a learning task from the data, such as hiding a word.
3. Ask the model to predict the missing information.
4. Compare its prediction with the original data.
5. Calculate the loss and update the model's parameters using training.

## 3. Examples

- **LLMs:** Predicting the next token in a sequence.
- **BERT:** Predicting masked tokens in text.
- **Computer vision:** Learning image representations by predicting or matching different views of images.

## 4. Self-Supervised vs Supervised vs Unsupervised Learning

| Feature | Supervised | Unsupervised | Self-Supervised |
|---|---|---|---|
| Data | Labeled | Unlabeled | Usually unlabeled |
| Training signal | Human-provided labels | Structure in the data | Targets derived from the data |
| Goal | Predict outputs | Discover patterns | Learn useful representations or prediction skills |
| Example | Spam classification | Customer clustering | Next-token prediction |

## 5. Why Is It Important?

- Uses massive amounts of unlabeled data.
- Reduces the need for expensive manual labeling.
- Helps models learn general patterns and representations.
- Enables pretraining of large language models before fine-tuning for specific tasks.

## Remember

**Self-supervised learning creates its own training targets from the data.**

For example, ChatGPT's base-model pretraining uses next-token prediction: given previous tokens, the model learns to predict the next token. The training target comes from the text itself.
