# Parameters vs Hyperparameters

## 1. Parameters

Parameters are the **internal values a model learns from training data**.

They determine how the model processes inputs and generates predictions.

**Examples:**
- Weights
- Biases

**Example:** In a neural network, weights determine how strongly different inputs influence a neuron's output. During training, these values are updated using optimization.

## 2. Hyperparameters

Hyperparameters are **settings chosen to control the training process or model architecture**. They are generally set before training or adjusted through experimentation.

**Examples:**
- Learning rate
- Batch size
- Number of epochs
- Number of hidden layers
- Number of attention heads in a Transformer

**Example:** A learning rate controls how much the model's parameters change during each optimization step.

## 3. Key Differences

| Feature | Parameters | Hyperparameters |
|---|---|---|
| Meaning | Values learned by the model | Settings controlling training or architecture |
| How determined | Learned from data | Chosen or tuned |
| Updated during training | Yes, through optimization | Usually not by the model's standard optimizer |
| Examples | Weights, biases | Learning rate, batch size, epochs |
| Purpose | Make predictions | Control how the model learns or is configured |

## 4. Example: Training a Neural Network

Suppose we train a neural network to recognize cats and dogs.

- **Parameters:** The weights and biases learned from images.
- **Learning rate:** Controls the size of parameter updates.
- **Batch size:** Determines how many training examples are processed together.
- **Epochs:** Determines how many times the model goes through the training dataset.

The hyperparameters influence the training process, while training updates the parameters.

## 5. Parameters vs Hyperparameters in LLMs

For a Large Language Model (LLM):

- **Parameters:** Billions of learned weights.
- **Hyperparameters:** Learning rate, batch size, number of layers, hidden dimension, and number of attention heads.

The number of parameters is often used to describe a model's size, although it does not alone determine its capabilities.

## Remember

**Parameters are learned; hyperparameters are configured or tuned.**

Parameters determine what the model has learned, while hyperparameters influence how the model is built or trained.
