# Pretraining vs Fine-Tuning

## 1. Pretraining

Pretraining is the initial training stage in which a model learns general patterns from a large dataset.

The goal is to develop useful representations and capabilities that can later be reused for different tasks.

**Examples:**
- An LLM learns language patterns by predicting the next token.
- An image model learns visual features from a large collection of images.

### How It Works

1. Collect a large and diverse dataset.
2. Choose a training objective.
3. Train the model on the dataset.
4. Update model parameters to minimize the training loss.
5. Obtain a pretrained model that can be adapted to downstream tasks.

**Example:**

```text
Training Text
     ↓
Next-Token Prediction
     ↓
Calculate Loss
     ↓
Update Parameters
     ↓
Pretrained Language Model
```

## 2. Fine-Tuning

Fine-tuning is the process of continuing training on a pretrained model using a more specific dataset or objective to improve its performance for a particular task or behavior.

Instead of starting from random initialization, fine-tuning begins with parameters learned during pretraining.

**Examples:**
- Adapting an LLM to follow instructions.
- Specializing a language model for customer support.
- Fine-tuning an image model to classify specific medical images.

### How It Works

1. Start with a pretrained model.
2. Prepare task-specific or domain-specific training data.
3. Continue training using an appropriate objective.
4. Update some or all model parameters, depending on the method.
5. Evaluate the resulting model on the target task.

**Example:**

```text
Pretrained Language Model
          ↓
Domain-Specific Dataset
          ↓
      Fine-Tuning
          ↓
 Specialized Language Model
```

## 3. Key Differences

| Feature | Pretraining | Fine-Tuning |
|---|---|---|
| Starting point | Usually random initialization or an earlier pretrained checkpoint | An existing pretrained model |
| Data | Often large and diverse | Usually more task-specific |
| Objective | Learn general patterns or representations | Adapt to a target task or behavior |
| Compute | Often very expensive | Usually less expensive |
| Parameters | Typically trains a large portion of the model | May update all or only selected parameters |
| Result | Pretrained foundation model | Model adapted to a specific need |

These are typical patterns, not absolute rules. Fine-tuning can still require substantial compute, and pretraining datasets and objectives vary.

## 4. Example: Training ChatGPT-Style Models

A simplified LLM development pipeline can include several stages.

### Stage 1: Pretraining

The model learns statistical patterns in text by predicting the next token.

```text
Input:  The capital of France is
Target: Paris
```

The model repeatedly predicts tokens and updates its parameters based on the loss.

### Stage 2: Supervised Fine-Tuning (SFT)

The pretrained model is trained on examples of prompts and desirable responses to improve its instruction-following behavior.

```text
Prompt: Explain gravity in simple words.
Target: Gravity is the force that attracts objects toward each other.
```

### Stage 3: Preference Alignment

Some development pipelines use human feedback or other preference data to further align responses with desired behavior.

Methods may include Reinforcement Learning from Human Feedback (RLHF) or Direct Preference Optimization (DPO).

These stages are common examples, not a universal recipe used by every LLM.

## 5. Types of Fine-Tuning

### A. Full Fine-Tuning

Updates all or most of the model's parameters.

**Advantage:** Provides flexibility for substantial adaptation.

**Limitation:** Can require significant memory and computational resources.

### B. Parameter-Efficient Fine-Tuning (PEFT)

Updates a small number of additional or selected parameters while keeping most pretrained parameters frozen.

**Example:** Low-Rank Adaptation (LoRA).

**Advantage:** Often reduces memory requirements and training costs.

### C. Instruction Fine-Tuning

Trains a model on instruction-and-response examples to improve its ability to follow user instructions.

### D. Domain-Specific Fine-Tuning

Adapts a model to a particular field, such as law, medicine, finance, or customer support.

**Important:** Fine-tuning does not automatically make a model factually reliable or an expert. The quality of the data and evaluation matters.

## 6. Do We Always Need Fine-Tuning?

No. A pretrained model can sometimes perform a task directly through prompting.

| Approach | What Changes? | Example |
|---|---|---|
| Prompting | The input or instructions | Ask a model to summarize a report |
| Fine-tuning | Model parameters, or selected trainable components | Train a model on support conversations |
| RAG | The information supplied as context | Retrieve company policies before answering |

Use prompting when instructions are sufficient. Consider RAG when the model needs access to external or frequently updated information. Consider fine-tuning when examples of desired behavior or domain-specific patterns can improve performance.

These techniques can also be combined.

## 7. Pretraining vs Fine-Tuning vs Inference

| Stage | Purpose | Are Model Parameters Updated? |
|---|---|---|
| Pretraining | Learn broad patterns | Yes |
| Fine-tuning | Adapt an existing model | Yes, for the selected trainable parameters |
| Inference | Generate predictions or outputs | Normally no |

**Typical workflow:**

```text
Pretraining
    ↓
Pretrained Model
    ↓
Fine-Tuning (Optional)
    ↓
Adapted Model
    ↓
Inference
    ↓
Predictions or Responses
```

## 8. Remember

- **Pretraining:** Learn broad patterns from data.
- **Fine-tuning:** Adapt a pretrained model to a more specific task or behavior.
- **Full fine-tuning:** Update all or most model parameters.
- **PEFT:** Update only a small subset of parameters or added components.
- **Prompting:** Guide the model without changing its parameters.
- **Inference:** Use the trained model to produce outputs.

**Final takeaway:** Pretraining builds the foundation; fine-tuning adapts it; inference puts the resulting model to work.
