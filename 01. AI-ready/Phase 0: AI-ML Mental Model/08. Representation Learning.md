# Representation Learning

## 1. What Is Representation Learning?

Representation learning is a machine learning approach in which a model **automatically learns useful features or representations from raw data** instead of relying entirely on manually engineered features.

A representation is a numerical form of data that makes important patterns easier for a model to learn and use.

**Example: Image Recognition**

- Raw input: An image containing a cat.
- Learned representation: Numerical features capturing edges, textures, shapes, and other visual patterns.
- Output: The model predicts that the image contains a cat.

The model learns useful representations during training.

## 2. How Does It Work?

1. Feed raw data into the model.
2. Transform the input into numerical representations.
3. Learn patterns and features through training.
4. Use the learned representations for prediction or another task.

**Flow:**

```text
Raw Data
   ↓
Representation Learning
   ↓
Numerical Features / Embeddings
   ↓
Prediction or Downstream Task
```

## 3. What Is a Representation?

A representation is a numerical description of an input that captures information relevant to a task.

For example, a text representation might encode semantic relationships between words or sentences.

In modern deep learning, representations are often learned through multiple layers of a neural network.

**Example: Image Representations**

- Early layers may learn edges and simple textures.
- Intermediate layers may learn shapes and object parts.
- Deeper layers may learn complex patterns associated with objects.

These are general tendencies, not strict rules about what each layer learns.

## 4. Representation Learning vs Feature Engineering

| Feature | Representation Learning | Feature Engineering |
|---|---|---|
| Feature creation | Learned automatically from data | Designed manually using domain knowledge |
| Human effort | Often less manual feature design | Requires explicit feature design |
| Common applications | Deep learning, NLP, computer vision | Traditional ML and structured data |
| Example | Neural network learns image features | Manually calculate image color statistics |

Both approaches can be useful. Traditional machine learning often benefits from carefully engineered features, while deep learning can learn representations directly from raw or minimally processed data.

## 5. Representation Learning in Deep Learning

Deep learning models often learn hierarchical representations, where successive layers transform the input into increasingly task-relevant features.

**Example:**

```text
Image Pixels
     ↓
Edges and Textures
     ↓
Shapes and Object Parts
     ↓
Object-Level Features
     ↓
Classification: Cat
```

The learned representations help the model identify useful patterns without requiring a human to specify every feature.

## 6. Representation Learning in NLP and LLMs

Natural Language Processing (NLP) models represent text numerically because neural networks operate on numerical inputs.

### A. Word Embeddings

An embedding maps a word or token to a numerical vector.

For example:

```text
"king"   → [0.21, -0.43, 0.81, ...]
"queen"  → [0.18, -0.39, 0.77, ...]
"apple"  → [-0.52, 0.62, 0.14, ...]
```

These are illustrative values, not actual embeddings from a particular model.

Useful embeddings can encode semantic and syntactic relationships, although the exact information depends on how they are learned.

### B. Contextual Representations

Modern Transformer models generate representations that depend on context.

Consider the word *bank*:

- "I deposited money in the bank."
- "We sat beside the river bank."

The same word can receive different contextual representations because the surrounding words change its meaning.

### C. LLM Training

During pretraining, an LLM learns representations while optimizing a training objective, such as next-token prediction.

These representations help the model capture linguistic patterns, relationships, and contextual information useful for generating text.

## 7. Representation Learning vs Embeddings

| Concept | Meaning |
|---|---|
| Representation learning | The process of learning useful numerical features |
| Representation | The resulting numerical description of data |
| Embedding | A vector representation, often in a learned continuous space |

**Remember:** Embeddings are one form of representation, and learning embeddings is one form of representation learning.

## 8. Types of Representation Learning

### A. Supervised Representation Learning

The model learns useful representations using labeled training data.

**Example:** Learning image features while training a classifier to recognize animal species.

### B. Unsupervised Representation Learning

The model learns structure from unlabeled data without relying on manually supplied target labels.

**Example:** Learning compact representations of customer behavior.

### C. Self-Supervised Representation Learning

The model creates training targets from the data itself and learns representations through these automatically generated objectives.

**Example:** Training a language model to predict the next token.

### D. Contrastive Learning

The model learns representations by bringing related examples closer together in representation space and separating unrelated examples, according to a defined training objective.

**Example:** Learning image representations that associate different views of the same object.

## 9. Why Is Representation Learning Important?

- Reduces dependence on manually engineered features.
- Helps discover complex patterns in raw data.
- Supports transfer learning and fine-tuning.
- Enables semantic representations of text, images, audio, and other data.
- Provides the foundation for many modern deep learning systems.

## 10. Remember

- **Representation learning:** Automatically learning useful features from data.
- **Representation:** A numerical description of the input.
- **Embedding:** A vector representation of an input.
- **Contextual representation:** A representation that changes according to context.
- **Self-supervised learning:** A common way to learn representations from unlabeled data.

**Final takeaway:** Representation learning transforms raw data into useful numerical features that help models recognize patterns and perform tasks. In modern AI, learned representations are a major reason neural networks can work with complex data such as language and images.
