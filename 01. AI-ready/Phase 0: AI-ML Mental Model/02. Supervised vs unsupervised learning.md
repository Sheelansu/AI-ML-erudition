# Supervised vs Unsupervised Learning

## 1. Supervised Learning

The model learns from **labeled data**, where inputs are paired with correct outputs.

**Examples:**
- **Classification:** Classifying emails as spam or not spam.
- **Regression:** Predicting house prices.

**Example:**

| Input | Label |
|---|---|
| Email content | Spam |
| Email content | Not Spam |

The model learns to predict labels for new, unseen data.

## 2. Unsupervised Learning

The model learns patterns or structures from **unlabeled data**, without predefined correct outputs.

**Examples:**
- **Clustering:** Grouping customers by purchasing behavior.
- **Dimensionality reduction:** Reducing the number of features while preserving useful information.

**Example:**

A model groups customers into different segments based on their shopping habits, without being given predefined groups.

## Key Differences

| Feature | Supervised Learning | Unsupervised Learning |
|---|---|---|
| Data | Labeled | Unlabeled |
| Goal | Predict an output | Discover patterns |
| Common tasks | Classification, regression | Clustering, dimensionality reduction |
| Example | Spam detection | Customer segmentation |

## Remember

- **Supervised:** Learn from examples with answers.
- **Unsupervised:** Discover patterns without provided answers.
