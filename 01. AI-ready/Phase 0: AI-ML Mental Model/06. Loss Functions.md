# Loss Functions

## 1. What Is a Loss Function?

A loss function measures **how far a model's prediction is from the correct target**.

It produces a numerical value called *loss*. During training, the model attempts to minimize this loss by adjusting its parameters.

- Lower loss generally indicates better predictions on the evaluated data.
- Higher loss generally indicates worse predictions.
- Zero loss indicates perfect predictions under that particular loss function.

## 2. How Does It Work?

1. Feed input data into the model.
2. The model generates a prediction.
3. Compare the prediction with the actual target using a loss function.
4. Calculate gradients through backpropagation.
5. Use an optimizer to update the model's parameters.
6. Repeat the process to reduce loss.

**Flow:**

`Input → Prediction → Loss Calculation → Backpropagation → Parameter Update`

## 3. Common Loss Functions

### A. Mean Squared Error (MSE)

**Used for:** Regression problems.

MSE calculates the average squared difference between predicted and actual values.

**Formula:**

```text
MSE = (1/n) * Σ (yᵢ - ŷᵢ)²
```

Where:
- `n` = number of observations
- `yᵢ` = actual value
- `ŷᵢ` = predicted value
- `Σ` = sum over all observations

**Example:** Predicting house prices.

**Key point:** Squaring errors penalizes large mistakes more heavily, making MSE sensitive to outliers.

### B. Mean Absolute Error (MAE)

**Used for:** Regression problems.

MAE calculates the average absolute difference between predicted and actual values.

**Formula:**

```text
MAE = (1/n) * Σ |yᵢ - ŷᵢ|
```

The variables have the same meanings as in MSE.

**Example:** Predicting delivery times.

**Key point:** MAE is less sensitive to large errors than MSE because it uses absolute differences rather than squared differences.

### C. Huber Loss

**Used for:** Regression problems, particularly when data contains outliers.

Huber loss combines the strengths of MSE and MAE. It behaves quadratically for small errors and linearly for large errors.

**Formula:**

```text
error = |y - ŷ|

if error <= δ:
    loss = 0.5 * error²
else:
    loss = δ * (error - 0.5 * δ)
```

Where:
- `y` = actual value
- `ŷ` = predicted value
- `δ` = threshold controlling the transition between quadratic and linear behavior

**Example:** Predicting house prices when a few properties have unusually high prices.

**Key point:** Huber loss is less sensitive to outliers than MSE while remaining smooth around zero error.

### D. Binary Cross-Entropy

**Used for:** Binary classification, such as spam versus not spam.

**Formula:**

```text
L = -[y * log(p) + (1-y) * log(1-p)]
```

Where:
- `y` = actual label, either `0` or `1`
- `p` = predicted probability of class `1`
- `log` = natural logarithm

**Example:** Email spam detection.

**Key point:** It penalizes predictions that assign low probability to the correct class, especially when the model is confidently wrong.

### E. Categorical Cross-Entropy

**Used for:** Multiclass classification.

**Formula:**

```text
L = -Σ yₖ * log(pₖ)
```

Where:
- `K` = number of classes
- `yₖ` = target indicator for class `k`
- `pₖ` = predicted probability of class `k`
- `Σ` = sum over all classes

**Example:** Classifying an image as a cat, dog, or bird.

**Key point:** For a one-hot target, the loss is the negative logarithm of the probability assigned to the correct class.

### F. Hinge Loss

**Used for:** Margin-based classification, particularly Support Vector Machines (SVMs).

**Formula for binary classification:**

```text
L = max(0, 1 - y * f(x))
```

Where:
- `y` = actual class label, either `-1` or `+1`
- `f(x)` = model's real-valued decision score

**Example:** Classifying images into two categories using a linear SVM.

**Key point:** Hinge loss penalizes incorrect predictions and correct predictions that do not achieve the desired margin. Predictions that are correct with a sufficient margin incur zero loss.

Unlike cross-entropy, hinge loss does not directly model class probabilities.

### G. Next-Token Prediction Loss

**Used for:** Training autoregressive Large Language Models (LLMs).

LLMs commonly use cross-entropy loss to train the model to predict the next token in a sequence.

**Example:**

```text
Input:  The sun rises in the
Target: east
```

If the model assigns a low probability to `east`, the loss is high. If it assigns a high probability, the loss is low.

**Key point:** The model learns to predict the next token by minimizing loss across training sequences.

## 4. Quick Comparison

| Loss Function | Typical Use | Main Characteristic |
|---|---|---|
| MSE | Regression | Strongly penalizes large errors |
| MAE | Regression | More robust to outliers than MSE |
| Huber Loss | Regression | Combines quadratic and linear penalties |
| Binary Cross-Entropy | Binary classification | Evaluates predicted class probabilities |
| Categorical Cross-Entropy | Multiclass classification | Evaluates probability assigned to the correct class |
| Hinge Loss | Margin-based classification | Encourages correct predictions with a sufficient margin |
| Next-Token Cross-Entropy | LLM training | Rewards assigning high probability to the correct next token |

## 5. Loss Function vs Optimizer

| Loss Function | Optimizer |
|---|---|
| Measures prediction error | Updates model parameters |
| Defines the training objective | Uses gradients to determine parameter updates |
| Example: Cross-Entropy | Example: Adam or SGD |

The loss function defines **what the model should minimize**. The optimizer determines **how to adjust the parameters** to minimize it.

### Training Flow

```text
Input Data
    ↓
Forward Pass
    ↓
Predictions
    ↓
Loss Calculation
    ↓
Backpropagation (Calculate Gradients)
    ↓
Optimizer Updates Parameters
    ↓
Repeat
```

## 6. Loss vs Accuracy

Loss and accuracy measure different things.

- **Loss:** Measures prediction error according to a mathematical function.
- **Accuracy:** Measures the proportion of predictions classified correctly.

A model can have the same accuracy as another model but a different loss because their predicted probabilities may differ.

Minimizing training loss also does not guarantee good performance on unseen data. Validation data helps evaluate generalization.

## 7. When Should You Use Each Loss?

- **MSE:** When large prediction errors should be penalized heavily.
- **MAE:** When you want a straightforward error measure that is less sensitive to outliers.
- **Huber Loss:** When you want a compromise between MSE and MAE.
- **Binary Cross-Entropy:** When predicting probabilities for two classes.
- **Categorical Cross-Entropy:** When predicting probabilities across multiple classes.
- **Hinge Loss:** When training margin-based classifiers such as SVMs.
- **Next-Token Cross-Entropy:** When training autoregressive language models.

## 8. Remember

- **MSE:** Large errors receive disproportionately large penalties.
- **MAE:** Errors are penalized in proportion to their absolute magnitude.
- **Huber:** MSE-like behavior for small errors and MAE-like behavior for large errors.
- **Cross-Entropy:** Measures how well predicted probabilities match the target.
- **Hinge:** Encourages correct classifications with a sufficient margin.
- **LLM Training:** Uses next-token prediction to learn language patterns.

**Final takeaway:** A loss function defines the mathematical objective that a model attempts to minimize during training. The choice of loss function depends on the task, the target, and the kinds of errors you want to penalize.
