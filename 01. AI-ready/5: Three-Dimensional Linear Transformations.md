## 1. Recap: From 2D to 3D

In the previous chapters, we learned that:

- A vector can be represented as an arrow or an ordered list of numbers.
- Every vector can be constructed from a linear combination of basis vectors.
- A linear transformation preserves vector addition and scalar multiplication.
- A matrix represents a linear transformation.
- Matrix multiplication combines successive linear transformations.

So far, we have primarily worked with two-dimensional vectors.

For example:

```text
v = [x, y]
```

A 2D vector has two components and can be visualized in a plane.

But the same principles apply to three-dimensional space.

```text
v = [x, y, z]
```

A 3D vector has three components and can be visualized in physical space.

**The central idea of this chapter is that linear transformations in 3D work exactly like those in 2D, except that we now have three independent basis directions instead of two.**

This means we can represent a 3D linear transformation using a 3x3 matrix.

---

## 2. The Three Standard Basis Vectors

In 2D, we used two standard basis vectors:

```text
i = [1, 0]
j = [0, 1]
```

They point along the x-axis and y-axis, respectively.

In 3D, we introduce a third basis vector:

```text
i = [1, 0, 0]
j = [0, 1, 0]
k = [0, 0, 1]
```

These vectors point along three independent coordinate axes:

- `i` points along the x-axis.
- `j` points along the y-axis.
- `k` points along the z-axis.

Each is a unit vector, meaning its length is 1.

### 2.1 Representing a vector using the basis vectors

Consider:

```text
v = [3, 2, 4]
```

We can construct this vector using the three basis vectors:

```text
v = 3*i + 2*j + 4*k
```

Expanding:

```text
v = 3*[1, 0, 0]
  + 2*[0, 1, 0]
  + 4*[0, 0, 1]
```

Multiply each vector by its scalar:

```text
v = [3, 0, 0]
  + [0, 2, 0]
  + [0, 0, 4]
```

Add the corresponding components:

```text
v = [3, 2, 4]
```

This gives us the same interpretation of coordinates that we developed in the earlier chapters.

**The coordinates of a vector tell us how much to scale each basis vector before adding them together.**

### 2.2 Why three basis vectors are necessary

In 2D, two independent directions are sufficient to reach every point in the plane.

In 3D, we need three independent directions to reach every point in space.

The third basis vector introduces movement along a direction that cannot be generated by combining the first two.

For example, no combination of `i` and `j` can produce:

```text
[0, 0, 1]
```

because both `i` and `j` have a zero third component.

The vector `k` provides that missing direction.

## 3. Visualizing a Transformation in 3D

In 2D, we imagined a coordinate grid being transformed.

For example:
- A rotation turns the grid.
- A scaling transformation stretches or compresses it.
- A shear transformation slants it.
- A projection can collapse the plane onto a line.

In 3D, we apply the same idea to the entire coordinate space.

Imagine a 3D grid made of evenly spaced, parallel lines running along the x, y, and z directions.

A linear transformation moves every vector to a new location.

Instead of tracking every vector separately, we can observe what happens to the grid and its three basis vectors.

### 3.1 What stays true?

A 3D linear transformation preserves the fundamental properties of linearity:

- The origin remains fixed.
- Straight lines remain straight, although they can collapse into points.
- Parallel lines remain parallel.
- Linear combinations are preserved.

However, lengths, angles, and volumes are not necessarily preserved.

For example, a transformation can stretch space along one axis while compressing it along another.

### 3.2 Why the grid helps

The grid provides a visual summary of the transformation.

If we understand where the three basis vectors end up, we can understand how the entire space is transformed.

This is the same principle used in 2D, extended to one additional dimension.

## 4. A 3D Linear Transformation Is Determined by Three Vectors

This is the most important conceptual idea in the chapter.

In 2D, a linear transformation is completely determined by where the two standard basis vectors go.

In 3D, it is completely determined by where the three standard basis vectors go.

Suppose a transformation `T` maps the basis vectors to the following destinations:

```text
T(i) = [a, d, g]
T(j) = [b, e, h]
T(k) = [c, f, l]
```

Now consider an arbitrary input vector:

```text
v = [x, y, z]
```

We know that:

```text
v = x*i + y*j + z*k
```

Apply the transformation:

```text
T(v) = T(x*i + y*j + z*k)
```

Because `T` is linear, it preserves this linear combination:

```text
T(v) = x*T(i) + y*T(j) + z*T(k)
```

Substitute the transformed basis vectors:

```text
T(v) = x*[a, d, g]
     + y*[b, e, h]
     + z*[c, f, l]
```

Multiply each vector by its scalar:

```text
T(v) = [a*x, d*x, g*x]
     + [b*y, e*y, h*y]
     + [c*z, f*z, l*z]
```

Add corresponding components:

```text
T(v) = [a*x + b*y + c*z,
        d*x + e*y + f*z,
        g*x + h*y + l*z]
```

We have now derived a formula for transforming any 3D vector.

The entire transformation is determined by just nine numbers.

---

## 5. Constructing a 3x3 Transformation Matrix

How do we store the three transformed basis vectors?

Exactly as we did in 2D: put them into the columns of a matrix.

Using our example:

```text
T(i) = [a, d, g]
T(j) = [b, e, h]
T(k) = [c, f, l]
```

The transformation matrix is:

```text
A = [a  b  c]
    [d  e  f]
    [g  h  l]
```

Each column represents the transformed image of one standard basis vector.

```text
First column  = T(i)
Second column = T(j)
Third column  = T(k)
```

This matrix completely describes the linear transformation.

### 5.1 General matrix-vector multiplication in 3D

For:

```text
A = [a  b  c]
    [d  e  f]
    [g  h  l]
```

and:

```text
v = [x, y, z]
```

The transformed vector is:

```text
A*v = [a*x + b*y + c*z,
       d*x + e*y + f*z,
       g*x + h*y + l*z]
```

Each output component is calculated using one row of the matrix.

The column interpretation explains the geometry, while the row-wise calculation provides a convenient numerical procedure.

## 6. Worked Example: A 3D Transformation

Suppose a transformation is represented by:

```text
A = [1  0  1]
    [0  2  0]
    [1  0  0]
```

Its columns tell us where the basis vectors go.

```text
T(i) = [1, 0, 1]
T(j) = [0, 2, 0]
T(k) = [1, 0, 0]
```

Notice that the transformed basis vectors are not necessarily the original unit vectors. A linear transformation can change their lengths and directions.

Now consider:

```text
v = [2, 3, 4]
```

Apply the matrix:

```text
A*v = [1*2 + 0*3 + 1*4,
       0*2 + 2*3 + 0*4,
       1*2 + 0*3 + 0*4]
```

Calculate each component:

```text
A*v = [2 + 4,
       6,
       2]
```

Therefore:

```text
A*v = [6, 6, 2]
```

### Geometric interpretation

The input vector can be constructed as:

```text
v = 2*i + 3*j + 4*k
```

After transformation:

```text
T(v) = 2*T(i) + 3*T(j) + 4*T(k)
```

Substituting the transformed basis vectors:

```text
T(v) = 2*[1, 0, 1]
     + 3*[0, 2, 0]
     + 4*[1, 0, 0]
```

Adding the results gives:

```text
T(v) = [6, 6, 2]
```

The geometric construction and the numerical matrix multiplication agree.

## 7. Understanding 3D Rotations

Rotations are an especially useful example of 3D transformations.

In 2D, a rotation happens around a single point, usually the origin.

In 3D, a rotation around the origin occurs about an axis.

Common examples include:
- Rotation around the x-axis.
- Rotation around the y-axis.
- Rotation around the z-axis.

Let's examine a few simple cases.

### 7.1 Rotation by 90 degrees around the z-axis

A 90-degree counterclockwise rotation in the xy-plane, leaving the z-coordinate unchanged, is represented by:

```text
R = [0  -1  0]
    [1   0  0]
    [0   0  1]
```

The transformation is:

```text
R*[x, y, z] = [-y, x, z]
```

For example:

```text
v = [2, 1, 3]
```

Applying the rotation:

```text
R*v = [-1, 2, 3]
```

The x and y coordinates rotate, while the z-coordinate remains unchanged.

The vector's length is preserved because this is a pure rotation.

### 7.2 Rotation by 90 degrees around the x-axis

One such rotation is represented by:

```text
Rx = [1  0   0]
     [0  0  -1]
     [0  1   0]
```

Its action is:

```text
Rx*[x, y, z] = [x, -z, y]
```

The x-coordinate remains unchanged while the y and z coordinates rotate.

### 7.3 Rotation by 90 degrees around the y-axis

One such rotation is represented by:

```text
Ry = [ 0  0  1]
     [ 0  1  0]
     [-1  0  0]
```

Its action is:

```text
Ry*[x, y, z] = [z, y, -x]
```

The y-coordinate remains unchanged while the x and z coordinates rotate.

**Important:** The signs in rotation matrices depend on the direction of rotation and the coordinate convention being used. The examples above use the usual right-handed coordinate system.

### 7.4 Why 3D rotations are more complex

In 2D, every rotation around the origin can be described by a single angle.

In 3D, a rotation also depends on the axis around which it occurs.

For example, rotating 90 degrees around the x-axis and then 90 degrees around the y-axis generally produces a different result from reversing that order.

This is another reason matrices are useful: they let us represent and combine rotations systematically.

## 8. Combining 3D Transformations

The principle from Chapter 4 still applies.

Suppose:
- `A` represents one 3D transformation.
- `B` represents another 3D transformation.

Applying `A` first and then `B` gives:

```text
result = B*(A*v)
```

The combined transformation is:

```text
C = B*A
```

The same matrix multiplication rules apply to 3x3 matrices as to 2x2 matrices.

### 8.1 Why composition matters in 3D

Consider a 3D object in a graphics application.

You might want to:
1. Rotate the object around the x-axis.
2. Rotate it around the y-axis.
3. Apply a scaling transformation.

The combined transformation can be represented by multiplying the corresponding matrices in the correct order.

```text
C = S*Ry*Rx
```

This means:
1. Apply `Rx` first.
2. Apply `Ry` second.
3. Apply `S` last.

The rightmost matrix acts first.

### 8.2 Matrix multiplication remains non-commutative

In general:

```text
A*B != B*A
```

The order of transformations matters.

However, matrix multiplication remains associative:

```text
(A*B)*C = A*(B*C)
```

You may change the grouping of a compatible product, but you generally cannot change the order.

## 9. Extending the Idea to Higher Dimensions

The same principle extends beyond 3D.

In an n-dimensional coordinate space, a vector has n components:

```text
v = [x1, x2, ..., xn]
```

The standard basis contains n vectors:

```text
e1 = [1, 0, ..., 0]
e2 = [0, 1, ..., 0]
...
en = [0, 0, ..., 1]
```

A linear transformation from n-dimensional space to itself is represented by an n-by-n matrix.

For example:

| Space | Basis vectors | Matrix size |
|---|---:|---|
| 2D to 2D | 2 | 2x2 |
| 3D to 3D | 3 | 3x3 |
| 4D to 4D | 4 | 4x4 |
| nD to nD | n | nxn |

For a linear transformation from n-dimensional space to m-dimensional space, the matrix has m rows and n columns.

This more general case will receive dedicated treatment later in the playlist.

### Key takeaway

The number of columns corresponds to the number of input dimensions.

The number of rows corresponds to the number of output dimensions.

This relationship is essential for understanding matrix shapes in machine learning.

## 10. Connection to AI and Machine Learning

The video focuses on geometric transformations, but the same mathematics underlies many machine learning operations.

### 10.1 High-dimensional feature vectors

A data point can be represented by many numerical features.

```text
x = [x1, x2, x3, ..., xn]
```

For example, a model might represent a customer using numerical features such as age, spending, transaction frequency, and other measurements.

Such a vector can live in a space with many dimensions, even though it cannot be visualized directly.

The mathematical rules for linear transformations remain the same.

### 10.2 Matrix transformations in neural networks

A neural network layer often performs a matrix-vector multiplication:

```text
y = W*x + b
```

Here:
- `x` is the input vector.
- `W` is a weight matrix.
- `b` is a bias vector.
- `y` is the output before applying an activation function.

If `x` has n components and `y` has m components, then `W` must have m rows and n columns.

The output dimension is determined by the number of rows in the weight matrix.

### 10.3 Why matrix dimensions matter

Suppose:

```text
x has 3 components
y has 2 components
```

Then the weight matrix has shape:

```text
W = 2x3
```

For example:

```text
W = [1  0  2]
    [0  3  1]
```

And:

```text
x = [2, 1, 4]
```

The output is:

```text
W*x = [1*2 + 0*1 + 2*4,
       0*2 + 3*1 + 1*4]
```

Therefore:

```text
W*x = [10, 7]
```

The transformation maps a 3D input vector into a 2D output vector.

This is a linear transformation between spaces of different dimensions, not a transformation from 3D to 3D.

### 10.4 Embeddings and hidden representations

In deep learning, an input can be transformed into a vector with a different number of components.

For example:

```text
input_embedding = [e1, e2, ..., e768]
```

A learned matrix can map this representation to a new space:

```text
output = W*input_embedding
```

The output might have a different number of dimensions, depending on the shape of `W`.

The geometric intuition from this chapter helps us understand that a matrix combines the input components to construct new output components.

The same mathematical principle applies whether a vector has 3 components or 3,000.

### 10.5 A subtle but important distinction

In a neural network, a matrix multiplication is linear, but adding a nonzero bias makes the operation affine.

Applying a nonlinear activation function, such as ReLU, generally makes the overall layer nonlinear.

The transformation concepts in this chapter explain the linear part of those computations.

## 11. Common Misconceptions to Avoid

1. **3D linear transformations do not require entirely new rules.** They extend the 2D principles to one additional dimension.
2. **A 3D vector has three components.** Each component describes its coordinate along one of the three axes.
3. **A 3D transformation matrix has three columns.** Each column represents the transformed image of one standard basis vector.
4. **The columns have geometric meaning.** They describe where the three original basis directions end up.
5. **The rows have a computational meaning.** They help calculate each output component.
6. **A transformation can change lengths and angles.** General linear transformations do not preserve them.
7. **Rotations are a special kind of linear transformation.** They preserve lengths and angles when performed about the origin.
8. **The order of 3D rotations matters.** Rotations around different axes generally do not commute.
9. **Matrix multiplication follows the same rules in 2D and 3D.** Only the matrix dimensions change.
10. **Higher-dimensional vectors do not need to be physically visualizable.** Their components and transformations can still be manipulated mathematically.

## 12. Quick Revision Sheet

| Concept | Meaning |
|---|---|
| 3D vector | A vector with three components |
| Standard basis | Three unit vectors along the x, y, and z axes |
| 3D linear transformation | A linear mapping of 3D vectors to 3D vectors |
| 3x3 matrix | A matrix representing a 3D-to-3D linear transformation |
| Matrix column | The transformed image of a standard basis vector |
| Matrix row | Contributes to calculating one output component |
| 3D rotation | A rotation around an axis through the origin |
| Composition | Combining successive transformations through matrix multiplication |
| Higher-dimensional vector | A vector with more than three components |
| Matrix shape | Rows determine output dimensions; columns determine input dimensions |

### Essential formulas

**Representing a 3D vector**

```text
v = [x, y, z]

v = x*i + y*j + z*k
```

**Standard basis vectors**

```text
i = [1, 0, 0]
j = [0, 1, 0]
k = [0, 0, 1]
```

**3D transformation matrix**

```text
A = [a  b  c]
    [d  e  f]
    [g  h  l]
```

**Matrix-vector multiplication**

```text
A*[x, y, z] = [a*x + b*y + c*z,
               d*x + e*y + f*z,
               g*x + h*y + l*z]
```

**Composition of transformations**

```text
C = B*A

C*v = B*(A*v)
```

**Dimension rule**

```text
(m x n matrix) * (n-component vector)
    = (m-component vector)
```

## Final Takeaway

This chapter demonstrates that **linear algebra scales naturally from 2D to 3D and beyond**.

In 2D, two basis vectors determine a linear transformation. In 3D, three basis vectors determine it. Their transformed coordinates become the columns of a matrix.

The essential reasoning is:

1. Every 3D vector is a linear combination of three standard basis vectors.
2. A linear transformation preserves that linear combination.
3. Knowing where the three basis vectors go determines the output for every vector.
4. Those transformed basis vectors form the columns of a 3x3 matrix.
5. Matrix multiplication calculates the transformed vector and combines successive transformations.

**The important habit:** When you see a transformation matrix, think about where each basis vector goes. The numbers become much easier to interpret once you understand the geometric transformation they describe.

That intuition will be particularly valuable in the next chapter, where we study the determinant and discover how transformations change area and volume.
